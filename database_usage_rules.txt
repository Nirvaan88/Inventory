How to switch databases — 3 ways
Way 1 — npm command (easiest, one command in terminal)
bash
npm run use:local    # → connects to your Office PC SQL Server
npm run use:server   # → connects to AWS SQL Server
npm start            # then start as usual
Way 2 — Edit .env file directly
Open .env and change just one line:

env
DB_MODE=local    # ← local Office PC (Windows Auth, no password needed)
DB_MODE=sql      # ← AWS Server (uses sa / Admin@123)
Then npm start.

Way 3 — Environment variable (temporary, no file change)
bash
# PowerShell
$env:DB_MODE="sql"; npm start        # server
$env:DB_MODE="local"; npm start      # local
What each mode does
Mode	Auth	Server	Who uses it
local	Windows Auth (no password)	KSNLPT642 (your PC)	Local development
sql	sa / Admin@123	localhost:1433	AWS Server (via pm2)
NOTE

The .env file is now in .gitignore so your passwords won't accidentally get pushed to GitHub. The AWS server uses ecosystem.config.js (which is also separate) — the .env file is only for local development.
